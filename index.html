Library

    • Add EPUBs with +. Books are stored on this device only.
    • The layers icon sets how many chapters go on one page.
    • Read aloud (headphones on the reading page) uses the system voice, follows the text, skips by paragraph and carries on into the next chapters. The screen stays on while a book is open.
    • Safari’s Listen to Page (Aa menu) keeps going with the screen locked, but stops at the end of each page.
    • Tap a paragraph for a bubble: headphones reads aloud from there, and the page icon starts a new page there for Listen to Page.
